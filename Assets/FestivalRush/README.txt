FESTIVAL RUSH  -  Diwali Night Run
An endless 3-lane runner (inspired by Subway Surfers) with a festival theme.
Works in Unity 2021.3 LTS, 2022.3 LTS and Unity 6. Built-in or URP pipeline.

HOW TO IMPORT
1. Create a new Unity project (template "3D" / "3D (Built-in)" or "Universal 3D").
2. Assets > Import Package > Custom Package...  and pick FestivalRush.unitypackage
   (or unzip FestivalRush_Assets.zip and drag the FestivalRush folder into the Project window).
3. Open  Assets/FestivalRush/FestivalRush.unity  and press PLAY.
   If the scene ever looks empty, use the top menu:  Festival Rush > Create Game Scene.

CONTROLS
  Left / Right  or  A / D        change lane
  Up / W / Space                 jump
  Down / S                       slide (in the air = fast fall)
  Phone: swipe left/right/up/down.  Tap or Space to start / restart.

GAMEPLAY
  Orange barricade        -> JUMP over it
  Toran gate (marigolds)  -> SLIDE under it
  Festival float (cart)   -> CHANGE LANE
  Gold coins              -> +10 points each
  BLUE orb   = Magnet (pulls coins in)
  GREEN orb  = Rangoli Shield (survive one hit)
  PINK orb   = 2x score
  Speed rises over time. Best score is saved.

SCRIPTS (Assets/FestivalRush/Scripts)
  GameManager.cs       game states, score, power-ups, UI, environment, fireworks timer
  PlayerController.cs  lanes, jump, slide, collisions, character model & animation
  TrackSpawner.cs      endless street, decorations, obstacle patterns, coins, power-ups
  CameraFollow.cs      runner camera
  Coin.cs / PowerUp.cs / Obstacle.cs / Spinner.cs / Firework.cs
  FRCore.cs            colours, materials, input (old + new Input System), sound effects

TUNING: select the "FestivalRush" object and change values on GameManager
(start speed, max speed, acceleration, power-up durations).

ANDROID BUILD: File > Build Settings > Android > Switch Platform > Build.

Everything (models, lights, sounds, UI) is generated by code, so you can replace any
part with your own 3D models later.
