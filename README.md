# Subway Surfers – Festival Edition: Diwali Special

A 3D endless-runner game set on a Diwali festival railway route, built in Unity 6 from a **single C# script**.

> **Disclaimer:** This is an independent, fan-made student prototype. It is not affiliated with or endorsed by SYBO or the official Subway Surfers game. All characters, 3D models, textures, music and sound effects are original and generated procedurally in code.

---

## Features

### Gameplay
- Three-lane railway running (left, middle, right) with smooth lane switching
- Automatic forward running that speeds up over the run
- Jump over low obstacles, slide under hanging ones, switch lanes around tall ones
- A side bump is forgiven once; a second bump within a few seconds ends the run
- Reach **3,000 m** to complete the festival and see the victory celebration
- Score from distance travelled and from collectibles, with a saved best score

### Collectibles
| Item | Reward |
|---|---|
| Golden Diwali coin | +1 coin, +10 score |
| Glowing diya | +3 coins, +50 score |
| Festival token | +2 coins, +30 score |
| Lakshmi Lotus (rare) | +100 score and **x2 score for 10 seconds** |
| Festival completion | +1,000 bonus |

### Obstacles
| Obstacle | How to pass |
|---|---|
| Railway barrier | Jump |
| Wooden crates (gift-wrapped) | Jump |
| Flower baskets (marigolds) | Jump |
| Low decorative toran arch | Slide |
| "HAPPY DIWALI" hanging sign | Slide |
| Festival decoration stand (tiered diyas) | Change lane |
| Station luggage cart | Change lane |

### Festival world
- Colourful Indian houses with lit arched windows, balconies, rooftop chhatri domes and string lights
- Glowing diyas lining the tracks, doorsteps and balconies
- Rangoli patterns, marigold garlands, mango-leaf torans and hanging lanterns (akash kandil)
- Grand toran gates with bells and a golden kalash
- Festival market stalls with sweets, diyas and striped canopies
- A decorated "DEEPAWALI JN." railway station with platforms and signboards
- Distant temples, fireworks in the night sky, floating sky lanterns and golden sparkles
- Colour palette: royal purple, saffron, gold, crimson, peacock blue and festive pink

### Player character
**Arjun**, an original runner in a saffron kurta with gold trim, a purple jacket, cream churidar, a pink safa (turban) and a peacock-blue dupatta, carrying a lit sparkler. Animations for running, jumping, landing, sliding, crashing and celebrating are all procedural.

### Audio (all generated in code)
- Original background music with plucked sitar-style melody, tanpura-style drone, tabla rhythm and manjira cymbals
- Sounds for coins, diyas, jumping, sliding, landing, lane switching, collisions, button clicks, fireworks, game over and victory
